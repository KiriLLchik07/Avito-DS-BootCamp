# Детекция автоматизированного трафика

Решение тестового задания Avito DS BootCamp. Основной файл - `solution.ipynb`: он загружает исходные CSV из `data/`, строит признаки по событиям внутри индивидуального суточного окна, проводит временную валидацию и создаёт `submission.csv`. `metric.py` содержит предоставленную организаторами метрику Precision при Recall ≥ 70%.

## Воспроизведение

Использован Python 3.12.13; точные версии прямых зависимостей указаны в `requirements.txt`. Откройте ноутбук из корня проекта и выполните **Restart Kernel and Run All**. На выходе появится `submission.csv` с колонками `cookie_id,score` в порядке `data/sample_submission.csv`. Случайное зерно - 42, CatBoost обучается на CPU с четырьмя потоками.

## Подход и оценка

Из истории событий каждого cookie строятся агрегаты активности, пауз и сессий, просмотров, поиска, географии, указателя и времени суток. Текущий кандидат - CatBoost на 110 признаках, включая группы платформы и User-Agent. Семейства User-Agent и ОС связываются с признаками по `cookie_id`. Параметры: глубина 5, learning rate 0.05, L2 10, 675 деревьев, без весов классов.

Разбиение идёт по дате начала окна: A - проверка 10–12 апреля, B - 13–16 апреля, C - 17–19 апреля 2026 года. После исправления привязки UA/OS и при неизменных параметрах Precision@Recall≥0.70 составила **0.7407** на A, **0.6944** на B и **0.7278** на C.

После проверки текущая модель обучается на всех размеченных куках. Ноутбук сохраняет новый прогноз в `submission.csv` и `artifacts/submission_ua_fixed.csv`. Скрытая метрика этого кандидата пока неизвестна.

Дополнительно сравнили LightGBM и XGBoost на исправленных признаках. Вариант XGBoost глубины 4 получил P@R≥0.70 **0.7619 / 0.7190 / 0.7107** на A/B/C соответственно: он лучше CatBoost на A и B, но хуже на C. Его прогноз сохраняется отдельно в `artifacts/submission_xgb_depth4.csv`; скрытая метрика также пока неизвестна.

Затем Optuna проверила 40 конфигураций XGBoost с фиксированным seed 42. Лучшая по A/B дала **0.7547 / 0.7404 / 0.7000** на A/B/C. Более ровная среди трёх лидеров дала **0.7767 / 0.7220 / 0.7273**. Ноутбук сохраняет оба прогноза в `artifacts/submission_xgb_optuna_ab.csv` и `artifacts/submission_xgb_optuna_stable.csv`. Период C уже использовался в предыдущих сравнениях, поэтому его оценка не является независимой проверкой. Результаты поиска сохраняются локально в `artifacts/optuna_xgb.sqlite3`; повторный запуск ноутбука использует их без повторения завершённых испытаний.

Отдельный поиск Optuna по 32 конфигурациям CatBoost включал исходную модель как контроль. Лучший вариант по A/B получил **0.7265 / 0.7190 / 0.7019** на A/B/C. Более устойчивый среди трёх лидеров получил **0.7547 / 0.7068 / 0.7386**, превысив исходный CatBoost на каждом отрезке. Прогнозы сохраняются в `artifacts/submission_catboost_optuna_ab.csv` и `artifacts/submission_catboost_optuna_stable.csv`; результаты поиска — в `artifacts/optuna_catboost.sqlite3`. Скрытая метрика новых вариантов пока неизвестна.

Исходный файл `artifacts/submission_v1.csv` сохранён: он дал **0.78589** на Stepik до исправления UA/OS. Проверенные позднее v2 и v3 получили 0.77088 и 0.78019 соответственно.
