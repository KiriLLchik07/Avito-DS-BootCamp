# Детекция автоматизированного трафика

Решение тестового задания Avito DS BootCamp. Основной файл - `solution.ipynb`: он загружает исходные CSV из `data/`, строит признаки по событиям внутри индивидуального суточного окна, проводит временную валидацию и создаёт `submission.csv`. `metric.py` содержит предоставленную организаторами метрику Precision при Recall ≥ 70%.

## Воспроизведение

Использован Python 3.12.13; точные версии прямых зависимостей указаны в `requirements.txt`. Откройте ноутбук из корня проекта и выполните **Restart Kernel and Run All**. На выходе появится `submission.csv` с колонками `cookie_id,score` в порядке `data/sample_submission.csv`. Случайное зерно - 42, CatBoost обучается на CPU с четырьмя потоками.

## Подход и оценка

Из истории событий каждого cookie строятся агрегаты активности, пауз и сессий, просмотров, поиска, географии, указателя и времени суток. Итоговая модель - CatBoost на 110 признаках, включая группы платформы и User-Agent. Параметры: глубина 5, learning rate 0.05, L2 10, 675 деревьев, без весов классов.

Разбиение идёт по дате начала окна: A - проверка 10–12 апреля, B - 13–16 апреля, C - 17-19 апреля 2026 года. Для v1 Precision@Recall≥0.70 составила **0.7156** на A и **0.6850** на B. Более поздние кандидаты улучшали отдельные локальные проверки, но уступили v1 на скрытом тесте. Это ограничение временной валидации на небольшой выборке.

После выбора v1 переобучается на всех размеченных куках. Ноутбук сохраняет его прогноз в `submission.csv` и `artifacts/submission_v1.csv`. Результат Stepik: **0.78589**. Проверенные позднее v2 и v3 получили 0.77088 и 0.78019 соответственно.
