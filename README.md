# Детекция автоматизированного трафика

Решение тестового задания Avito DS BootCamp. Основной файл - `solution.ipynb`: он загружает исходные CSV из `data/`, строит признаки по событиям внутри индивидуального суточного окна, проводит временную валидацию и создаёт `submission.csv`. `metric.py` содержит предоставленную организаторами метрику Precision при Recall ≥ 70%.

## Воспроизведение

Использован Python 3.12.13; точные версии прямых зависимостей указаны в `requirements.txt`. Откройте ноутбук из корня проекта и выполните **Restart Kernel and Run All**. На выходе появится `submission.csv` с колонками `cookie_id,score` в порядке `data/sample_submission.csv`. Случайное зерно - 42, CatBoost обучается на CPU с четырьмя потоками.

## Подход и оценка

Из истории событий каждого cookie строятся агрегаты активности, пауз и сессий, просмотров, поиска, географии, указателя и времени суток. Текущий подтверждённый кандидат — CatBoost на 110 признаках, включая группы платформы и User-Agent. Семейства User-Agent и ОС связываются с признаками по `cookie_id`. Параметры выбранного испытания Optuna: 1050 деревьев, глубина 6, learning rate 0.0532, L2 26.43, seed 42, без весов классов.

Разбиение идёт по дате начала окна: A - проверка 10–12 апреля, B - 13–16 апреля, C - 17–19 апреля 2026 года. После исправления привязки UA/OS и при неизменных параметрах Precision@Recall≥0.70 составила **0.7407** на A, **0.6944** на B и **0.7278** на C.

Исходный исправленный CatBoost с 675 деревьями сохраняется в `artifacts/submission_ua_fixed.csv`. Итоговый `submission.csv` воспроизводит лучший проверенный вариант из `artifacts/submission_catboost_optuna_stable.csv`.

Дополнительно сравнили LightGBM и XGBoost на исправленных признаках. Вариант XGBoost глубины 4 получил P@R≥0.70 **0.7619 / 0.7190 / 0.7107** на A/B/C соответственно: он лучше CatBoost на A и B, но хуже на C. Его прогноз сохраняется отдельно в `artifacts/submission_xgb_depth4.csv`; скрытая метрика также пока неизвестна.

Затем Optuna проверила 40 конфигураций XGBoost с фиксированным seed 42. Лучшая по A/B дала **0.7547 / 0.7404 / 0.7000** на A/B/C. Более ровная среди трёх лидеров дала **0.7767 / 0.7220 / 0.7273**. Ноутбук сохраняет оба прогноза в `artifacts/submission_xgb_optuna_ab.csv` и `artifacts/submission_xgb_optuna_stable.csv`. Вариант `stable` получил **0.80637** на Stepik — ниже лучшего CatBoost. Период C уже использовался в предыдущих сравнениях, поэтому его оценка не является независимой проверкой. Результаты поиска сохраняются локально в `artifacts/optuna_xgb.sqlite3`; повторный запуск ноутбука использует их без повторения завершённых испытаний.

Отдельный поиск Optuna по 32 конфигурациям CatBoost включал исходную модель как контроль. Лучший вариант по A/B получил **0.7265 / 0.7190 / 0.7019** на A/B/C. Более устойчивый среди трёх лидеров получил **0.7547 / 0.7068 / 0.7386**, превысив исходный CatBoost на каждом отрезке. Прогнозы сохраняются в `artifacts/submission_catboost_optuna_ab.csv` и `artifacts/submission_catboost_optuna_stable.csv`; результаты поиска — в `artifacts/optuna_catboost.sqlite3`. Вариант `stable` получил **0.81566** на Stepik и пока остаётся лучшим скрытым результатом.

Дополнительно проверили точную строку User-Agent и самые частые категорию, локацию, поисковый запрос внутри окна. На A/B/C исходные 110 признаков дали **0.7547 / 0.7068 / 0.7386**; с точным UA — 0.7477 / 0.6984 / 0.7568, с интересами — 0.7442 / 0.7045 / 0.7386, с обоими блоками — 0.7512 / 0.6902 / 0.7517. Эти блоки не включены в итоговую модель, поскольку снизили метрику на A и B.

Четыре признака указателя с разделением по просмотру объявления и выдачи (доля событий с координатами и доля повторных позиций) дали **0.7767 / 0.6770 / 0.7179** на A/B/C. Из-за просадки на B и C этот блок также не включён в итоговую модель.

Для проверки компактных наборов важность признаков рассчитана только на обучающих датах до A. CatBoost с 20 признаками получил **0.7080 / 0.6468 / 0.6957**, с 40 — **0.7175 / 0.6580 / 0.8058**, с 60 — **0.7306 / 0.6824 / 0.7417** на A/B/C. На A и B полный набор из 110 признаков лучше. Прогноз 40-признакового варианта сохраняется отдельно в `artifacts/submission_catboost_top40.csv` как эксперимент; подтверждённый `submission.csv` не меняется.

На отдельных днях C 40 признаков уступили полному набору 17 апреля и выиграли 18–19 апреля. Стратифицированный bootstrap по кукам (500 повторов) дал 95% интервал разницы P@R≥0.70 **[−0.081; +0.111]**. Интервал включает ноль, поэтому скачок на всём C нельзя считать надёжным улучшением.

Исходный файл `artifacts/submission_v1.csv` сохранён: он дал **0.78589** на Stepik до исправления UA/OS. Проверенные позднее v2 и v3 получили 0.77088 и 0.78019 соответственно.
